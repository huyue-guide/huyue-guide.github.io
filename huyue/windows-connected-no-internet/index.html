Windows 上虎跃已连接但不能上网？按这套顺序排查

Windows 上最容易浪费时间的是一上来就“网络重置”。先确认原始网络是否正常、问题影响全部应用还是只有浏览器，再决定动哪一项。

更新于 2026 年 9 月
本页只处理 Windows 使用：如果其他设备也同时出现“连接后不能上网”，先回到 跨设备总览 判断是否属于线路或基础网络问题。
开启虎跃后所有程序都没网先断开测试原始网络，再检查系统代理和网络状态；只有域名解析异常时再查 DNS。
只有浏览器打不开优先看浏览器扩展、代理和缓存，不要先重置 Windows。
只有某个 App 不通先查应用自己的网络、代理或账户状态。
退出虎跃后仍然没网检查 Windows 是否残留手动代理或异常网络状态。

先断开虎跃，确认 Windows 本身能联网

如果断开后普通网页也打不开，先恢复电脑自己的 Wi‑Fi、有线网络或路由器连接。原始网络本身异常时，继续切虎跃节点不会解决问题。

断开后正常、连接后全部没网

重新连接一条线路做对照。如果仍是所有程序都失去网络，检查 Windows 的代理设置是否被其他工具手动修改，以及第三方安全软件或旧 VPN 客户端是否同时接管网络。若表现为“域名打不开、换网络就恢复”，再转到 DNS 专项排查，不要在这里同时改多组参数。

只有浏览器打不开

用另一个浏览器或无痕窗口测试。如果另一个浏览器正常，优先检查扩展、浏览器自己的代理设置和站点缓存。此时系统网络通常并没有整体断开。

只有某个平台打不开

ChatGPT、Netflix、YouTube 等平台都有自己的账户、地区和服务状态问题。其他网站正常时，不要把“单个平台异常”直接归成 Windows 网络故障。

退出虎跃后仍然没有网络

  1. 完全退出虎跃，而不是只点断开。
  2. 关闭并重新开启当前网络连接。
  3. 检查 Windows 的“代理”设置是否仍启用了手动代理。
  4. 重启电脑后再测试。

只有这些步骤都不能恢复时，才考虑 Windows 的网络重置。重置会影响已有网络配置，不建议作为第一步。

判断重点：“断开虎跃后网络是否立即恢复”是 Windows 上最有价值的对照之一。
