Windows 虎跃已连接但不能上网：按现象查代理、应用和 DNS

Windows 上不要一看到“已连接但没网”就做网络重置。先用断开虎跃这个对照，把问题分成原始网络故障、虎跃连接后整机断网、单个程序异常和退出后残留四类。

先做一个最重要的对照：断开虎跃后，如果其他网站也仍然打不开，先修复 Windows 自己的网络；如果断开后立刻恢复，再继续下面的虎跃相关检查。

情况一：连接虎跃后，所有程序一起没网

  1. 换一条线路重新连接，只改线路这一项。
  2. 如果仍然整机断网，完全退出其他 VPN、代理和网络过滤工具。
  3. 进入 设置 → 网络和 Internet → 代理，确认没有旧工具留下的陌生手动代理。
  4. 再用手机热点做一次对照。如果热点正常、原 Wi‑Fi 不正常，优先查当前网络环境，而不是继续改 Windows。

情况二：浏览器打不开，但其他程序正常

这时 Windows 网络通常没有整体中断。用另一款浏览器或无痕窗口测试；如果能打开，检查扩展、浏览器代理、缓存和安全软件的网页过滤。不要因为一个浏览器失败就重置网卡。

情况三：只有一个桌面 App 不通

优先检查该 App 是否设置了自己的 Proxy、是否需要完全退出重开，以及防火墙或安全软件是否单独限制它。比如 Telegram Desktop 有独立代理设置，不能用“浏览器能上网”直接推断它的代理配置也正常。

情况四：网页像是有网络，但域名经常打不开

这种表现才更值得查 DNS。先比较手机热点和当前 Wi‑Fi；如果只有一个网络下出现域名解析异常，再进入 DNS 异常检查。不要在整机断网时把 DNS 当第一原因。

退出虎跃后仍然没有网络

  1. 确认是“完全退出”虎跃，而不只是点击断开。
  2. 检查 Windows 手动代理是否仍启用。
  3. 关闭再开启 Wi‑Fi，或重新连接有线网络。
  4. 退出其他 VPN、代理和网络过滤软件，再重启电脑测试。

只有原始网络长期异常、常规代理和网络状态检查都无效时，才考虑 Windows 的网络重置。它会影响网卡和已有网络配置，不应作为首选步骤。

快速判断：“换手机热点后是否恢复”通常比连续换多个节点更能判断问题是在本地网络还是电脑设置。
