虎跃 Windows 使用教程：首次连接、模式设置与系统网络检查

Windows 上先把“虎跃有没有连上”和“某个程序能不能联网”分开判断。首次使用保持默认设置即可；出现异常时，再针对系统代理、浏览器、桌面应用或 DNS 逐项排查。

第一次使用安装后先用默认设置连接，确认普通网页和目标应用都能访问。
所有程序一起没网先断开虎跃验证原始网络，再检查代理、其他 VPN 和网络状态。
只有浏览器异常优先检查浏览器扩展、代理和缓存。
退出虎跃仍没网重点看 Windows 手动代理是否残留。

安装后第一次连接，先不要同时改很多设置

从虎跃当前官方入口取得 Windows 客户端后完成安装或解压。第一次连接时先保持默认线路和默认模式，连接成功后先打开一个普通网页，再打开你真正要使用的网站或 App。这样后面如果出现问题，能知道是基础网络、虎跃连接还是目标应用本身。

智能模式和全局模式怎么选

智能模式适合日常使用：中国大陆常用应用和网站直接使用本地网络，其他国家或地区的应用和网站通过加速线路。只有智能模式下某个应用无法正常访问时，再切到全局模式做对照。全局模式会让设备内更多流量经过加速线路，部分国内应用可能变慢。

Windows 的系统代理在哪里检查

如果出现“虎跃已断开，但浏览器仍然打不开网页”，进入 设置 → 网络和 Internet → 代理，查看是否仍启用了你不认识的手动代理或旧代理工具留下的配置。不要看到代理选项就全部删除：公司、学校或其他正式网络工具可能确实需要它。

只有 Chrome、Edge 或某个桌面 App 不通

先确认其他程序仍能联网。浏览器可用无痕窗口或另一款浏览器做对照，再检查扩展和浏览器自身代理；桌面 App 则看它是否有独立代理、是否需要完全退出重开，以及防火墙或安全软件是否只限制了该程序。

什么时候才需要检查 DNS

DNS 更适合处理“域名打不开、换网络后恢复、直接访问某些服务仍正常”这类表现。若所有程序在连接虎跃后立即失去网络，先排查线路、代理和其他 VPN；不要一上来同时改代理、DNS 和网卡。需要继续判断时可看 DNS 异常检查。

连接成功但整台电脑没网

这属于故障排查，不在本页重复所有步骤。直接进入 Windows 已连接但不能上网，按“原始网络 → 系统代理 → 浏览器/应用 → DNS”的顺序定位。

实用原则：一次只改一个变量。换线路后先测试，不要同时又改 DNS、代理和防火墙，否则恢复后也不知道是哪一步起作用。

Windows 上的线路和模式

Windows 端可使用 200+ 节点，并支持智能模式和全局模式。日常浏览先用智能模式或“智选最优线路”；只有指定地区内容，或某个桌面应用在智能模式下表现异常时，再手动选择地区或切到全局模式做对照。
