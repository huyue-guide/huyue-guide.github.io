虎跃加速器使用指南

已经安装但不知道怎么连接，或连接后出现没网、掉线、某个 App 不通？这里不从功能列表开始，而是按你现在的设备和症状选择处理方法。

先选最接近你现在的情况：还没安装 → 看下载安装；刚装好 → 看第一次使用；已经连接但打不开网页 → 直接进入连接故障排查。

第一次使用，从这三篇开始

还没安装下载与安装

按 Windows、Android、iPhone/iPad、Mac 选择正确安装方式。

已经安装连接、选线路和常见设置

先用智选最优线路，确认连接生效后再决定是否手动换节点。

最常见故障显示已连接但不能上网：先分设备

先判断全部没网、单个平台异常还是单设备故障，再进入 Windows、iPhone / iPad、Mac 等对应设备说明。

不知道从哪查通用网络排查

先判断问题范围，再决定要不要改节点、DNS 或系统设置。

按设备处理

Windows

连接后网页打不开、退出后仍没网、浏览器与应用表现不一致。

Android

VPN 授权、锁屏后断开、系统杀后台以及应用网络异常。

iPhone / iPad

首次 VPN 配置授权、连接状态判断、Wi‑Fi 与蜂窝网络对照测试。

 macOS

Mac 安装与网络异常

确认安装来源、VPN 权限、线路选择和旧网络工具冲突。

当前平台、线路与设备规则

支持平台Windows、Android、iPhone/iPad、Mac；HarmonyOS 5.0.0.113 SP2 及以上需通过卓易通运行。
线路规模当前客户端提供 200+ 节点，覆盖多个常用国家和地区，并支持智能模式与全局模式。
流量VIP 与 SVIP 均不限流量，并提供数据加密保护及专业客服支持。
多设备同一账号可在电脑、Android、iPhone、平板等设备登录；可同时连接的数量取决于购买套餐时选择的同时在线设备数。

超过套餐支持的同时在线设备数后，部分设备可能无法连接或被自动断开。如果多台设备轮流出现掉线，先核对套餐的同时在线设备数，不要直接按网络故障处理。

VIP 与 SVIP 怎么选

项目VIP（普通套餐）SVIP（高级套餐）
线路使用 VIP 基础线路，不含高级节点可使用普通节点及高级节点，线路选择更丰富
ChatGPT部分线路可能可用，但没有 ChatGPT 专区节点，稳定性受线路和第三方平台影响提供由工作人员持续维护的 ChatGPT 专区节点
视频适合日常浏览、社交应用及最高 720P 高清视频支持 1080P 高清视频并可正常观看最高 4K 内容；实际播放仍会受到本地网络、当前线路波动和视频平台本身影响
自选线路以基础线路使用为主支持自选线路
同时在线设备按购买时选择的设备数购买一个同时在线设备数名额，可限时额外获赠一个；具体以购买页面显示为准

选择上：日常浏览和一般视频使用 VIP 即可；需要高级节点、ChatGPT 专区、自选线路或更高画质体验时，可选择 SVIP。

账号、密码、版本号与人工客服

忘记账号或密码先联系人工客服核实

可提供账号绑定的手机号码或邮箱；也可以提供付款订单号、付款时间及付款金额，或能清楚显示订单信息的付款截图。

修改密码“我的” → “账号与安全”

进入客户端右下角“我的”，点击“账号与安全”→“修改密码”，按提示输入当前密码和新密码后提交。

查看版本号“我的” → “关于我们”

“关于我们”右侧显示的数字就是当前客户端版本号。反馈故障时建议同时提供版本号和故障页面截图。

人工客服“官方服务” → “联系客服”

App 主界面底部进入“官方服务”，在支持页面点击绿色字体“联系客服”，也可直接打开客服入口。服务时间为每日 09:00—24:00（北京时间），全年 365 天。

遇到问题时，先别同时改很多设置

  1. 先确认断开虎跃后，原始 Wi‑Fi、蜂窝网络或有线网络是否正常。
  2. 再确认是所有网站/App 都异常，还是只有一个平台有问题。
  3. 原始网络正常、只有连接后异常时，再换一条线路做对照。
  4. 仍然失败，再检查设备上的 DNS、代理、后台限制或其他 VPN/网络工具。
为什么这样查：一次只改变一个变量，才知道到底是线路、设备、应用还是原始网络出了问题。
