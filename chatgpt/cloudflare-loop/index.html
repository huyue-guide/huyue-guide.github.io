ChatGPT 一直“正在检查你的浏览器”？Cloudflare 验证循环这样排查

这里说的是“浏览器检查一直过不去”：验证结束后再次验证，或者页面反复刷新却进不了 ChatGPT。它和已经进入 ChatGPT 后频繁弹 CAPTCHA 不是同一个问题。

先做一轮干净测试：临时关闭 VPN/代理和广告、隐私、脚本拦截扩展，确认 Cookie 与 JavaScript 可用，然后用无痕窗口重新打开 ChatGPT。

按这个顺序排，信息量最大

  1. 关闭 VPN 或代理：OpenAI 将这一项列为 Cloudflare 验证循环的首要排查动作之一。
  2. 允许 Cookie 和 JavaScript：尤其不要拦截 chatgpt.com、openai.com 和 auth.openai.com 的验证流程。
  3. 暂时停用广告、隐私和脚本拦截工具：它们可能让验证页面能显示，却无法保存验证结果。
  4. 使用无痕窗口或干净浏览器配置：如果这样能进入，问题更可能来自原浏览器环境。
  5. 换一个网络：公司 Wi-Fi 失败而手机热点正常时，应重点看企业网络过滤，而不是账号。

为什么“验证成功了”还会回来

Cloudflare 验证不是只看一个按钮是否点完。浏览器还需要正常执行脚本、保存 Cookie，并让后续请求通过同一套网络路径继续完成。如果这些环节被扩展、代理、过滤器或受管理网络中断，就可能表现为验证循环。

公司或学校网络一直循环

OpenAI 当前说明，受管理网络可能需要允许 Cloudflare challenge 相关请求。如果同一设备换到手机热点立即正常，应把这个结果告诉网络管理员，比继续重装浏览器更有用。

使用虎跃时怎么做

先完全关闭虎跃做一次基线测试；如果关闭后能通过验证，再连接虎跃测试不同线路。不要同时开启虎跃、系统代理和浏览器代理，否则很难判断是哪一层改变了验证路径。

如果你已经能进入 ChatGPT，只是使用过程中反复出现拼图或人机验证，请改看 CAPTCHA 频繁出现。
