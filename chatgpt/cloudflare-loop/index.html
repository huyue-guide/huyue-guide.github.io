ChatGPT 一直“正在检查你的浏览器”？Cloudflare 验证循环这样排查

能打开 ChatGPT 登录页，却一直卡在“正在检查你的浏览器”或验证完成后又重新开始，重点不是账号密码，而是浏览器环境和网络验证没有顺利完成。

更新于 2026 年 9 月
先做最小化测试：临时关闭 VPN/代理和广告拦截扩展，确认 Cookie 与 JavaScript 可用，再用无痕窗口打开 ChatGPT。如果这样能通过，就逐项恢复设置找出冲突项。
一直“Checking your browser”优先查 VPN/代理、脚本拦截、Cookie 和当前网络。
验证通过后又回来可能是 Cookie/会话没能保存，先换无痕窗口或干净浏览器配置。
公司/校园网络更容易出现受管理网络可能拦截 Cloudflare 验证或相关域名。
换移动网络就恢复说明当前 Wi‑Fi 或出口网络更值得优先排查。

第一步：先临时关闭 VPN 或代理

OpenAI 当前官方登录排障明确建议，遇到 Cloudflare 验证循环时先停用 VPN 或代理并刷新页面。这一步只是做对照，不代表所有 VPN 都一定导致问题。

如果关闭后马上可以登录，说明当前网络出口或代理链路可能影响了验证。先完成登录，再决定是否需要重新启用虎跃并换一条更稳定的线路。

第二步：检查 Cookie 和 JavaScript

Cloudflare 验证需要浏览器正常执行脚本并保存会话。确认 chatgpt.com、openai.com 和 auth.openai.com 没有被 Cookie 管理器、隐私扩展或脚本拦截器阻止。

不建议一上来清空整个浏览器历史。先用无痕窗口测试；如果无痕正常，再针对 OpenAI/ChatGPT 相关站点清理数据。

第三步：暂时停用广告与隐私拦截工具

某些广告拦截、反追踪或脚本控制扩展会让验证页面加载不完整。临时关闭后刷新一次，如果恢复，再逐个启用找出冲突项。

第四步：换网络，比连续换节点更有信息量

从 Wi‑Fi 切到手机数据，或反过来测试。如果只在某一个网络里出现验证循环，就优先处理那个网络环境；公司或校园网络还可能需要管理员放行 Cloudflare 验证相关流量。

使用虎跃时怎么处理

如果问题只在某条虎跃线路出现，可以先断开做对照，再换一条线路。不要同时改 DNS、浏览器扩展、代理和多个节点，否则很难判断是哪一项真正影响了验证。

验证循环和“密码错误”不是同一类故障。页面能进入 Cloudflare 检查但无法通过时，优先处理浏览器与网络环境，不要反复重置密码。
