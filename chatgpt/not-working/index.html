ChatGPT 打不开、Network Error 或 WebSocket 错误怎么排查

这页只处理“已经到了访问和连接这一层”的故障：网页空白、Network Error、WebSocket 连接错误、回答一直转圈或中途断开。登录验证码和 Cloudflare 循环不在这里处理。

最有效的第一步：先看 OpenAI 服务状态，再用同一设备切一次手机热点或另一条网络。这样可以很快区分“平台异常”和“当前网络路径异常”。

先把现象对上

现象优先检查
ChatGPT 和其他网站都打不开本地网络本身，不要先把问题归到 ChatGPT
只有 ChatGPT 打不开OpenAI 服务状态、当前网络过滤、DNS、代理/VPN
提示 Network Error连接稳定性、VPN/Proxy、浏览器扩展、网络切换
提示 WebSocket 连接错误防火墙、代理或企业网络是否允许 WebSocket
回答能开始但经常中途断开长连接稳定性，而不是账号密码

个人网络：一次只改一个变量

  1. 刷新页面或新建对话，再确认问题能否复现。
  2. 临时停用 VPN、代理或安全 DNS 做一次对照。OpenAI 的错误排查也把这些列为常见变量。
  3. 用无痕窗口测试；如果无痕正常，再检查浏览器扩展、缓存和 Cookie，而不是继续换线路。
  4. Wi-Fi 与手机热点互换测试。只有某一网络失败时，问题更可能在该网络的 DNS、过滤或出口。

企业、学校或受管理网络要看 WebSocket

OpenAI 当前网络指南说明，ChatGPT 的部分功能会使用安全 WebSocket；如果网络默认阻止 WebSocket、TLS 检查改写连接，或者代理提前关闭长连接，可能出现卡住、断线或无法流式输出。

如果你只能在公司或学校网络复现，通常应该让网络管理员检查 ChatGPT/OpenAI 相关域名以及 TCP 443 上的 WebSocket，而不是不断清缓存。

什么时候才测试虎跃

把虎跃当作一个“网络出口变量”使用：当前网络失败而另一网络正常时，可以分别测试关闭虎跃、连接不同线路后的结果。若关闭 VPN/代理后恢复，就不要继续叠加更多代理设置。

如果页面能打开但卡在账号登录，请转到 登录问题；如果一直停在“正在检查你的浏览器”，看 Cloudflare 验证循环。

如果同一网络下网页版正常、只有 App 异常，可继续看 App 与网页版对照排查 →
