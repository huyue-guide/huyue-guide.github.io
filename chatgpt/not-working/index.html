ChatGPT 打不开、Network Error 或一直加载？网络故障排查

如果你遇到的是打不开、空白页、Network Error、WebSocket、一直加载或生成卡住，按这里的连接问题顺序检查。登录验证码、Cloudflare 循环和 App/网页表现不同，应按对应现象处理。

更新于 2026 年 9 月
先看现象：其他网站是否正常、ChatGPT 是完全打不开还是连接中断、换网络是否恢复。先确认连接层问题，再动 VPN、代理或 DNS。
OpenAI 当前官方排障建议包括检查服务状态、刷新页面、清除缓存与 Cookie、使用无痕窗口、禁用可能干扰的扩展，以及在部分网络错误场景下关闭 VPN/代理测试。查看 OpenAI 官方排障
空白页 / 完全打不开

先看其他网站是否正常，再测无痕窗口和另一网络。

Network Error / WebSocket

优先做网络对照，并按 OpenAI 建议测试关闭 VPN、代理或安全 DNS。

一直 Thinking / Generating

先看服务状态，再新建对话、刷新或换浏览器。

完全打不开或页面空白

先测试其他网站是否正常。如果普通网页都正常，再尝试强制刷新、无痕窗口、不同浏览器，并暂时禁用脚本拦截或安全扩展。

提示 Network Error / WebSocket 错误

这类错误通常表示连接无法稳定建立。先换网络测试；如果正在使用 VPN、代理或安全 DNS，按 OpenAI 官方建议暂时关闭它们做对照。若关闭后恢复，就不要继续把问题简单归因于“节点不够快”。

一直卡在 Thinking / Generating

先检查 OpenAI 服务状态，再刷新或新建对话。如果只有很长的单个对话异常，可以新建聊天测试。还要排除浏览器扩展、代理和网络过滤。

如果其实是登录或验证问题

页面能打开、只是验证码收不到、登录后跳回登录页或卡在验证时，不属于这篇的核心范围。直接看 ChatGPT 登录失败与验证码排查；如果卡在 Cloudflare 浏览器检查，则看 Cloudflare 验证循环。

什么时候再测试另一种网络出口

如果你已经确认当前网络环境本身无法稳定连接，而换到另一网络后恢复，再测试不同网络出口才有意义。如果你正在用虎跃，可以把它作为其中一次对照；但遇到异常活动、WebSocket 或 VPN/代理相关提示时，应先按 OpenAI 官方建议关闭 VPN/代理测试。

只有登录环节出问题？ 如果页面能正常打开，但卡在验证码、验证登录或反复跳回登录页，单独看 ChatGPT 登录失败与验证码排查 更直接。
网页版和 App 表现不一样？ 如果同一账号只有原生 App 或只有浏览器异常，先看 ChatGPT App 与网页版差异排查，比重复清缓存更容易定位。
总是弹 CAPTCHA？ 如果不是卡在 Cloudflare 页面，而是使用过程中几乎每次都要求人机验证，单独看 ChatGPT CAPTCHA 频繁出现排查。
