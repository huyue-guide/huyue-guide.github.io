Telegram 手机正常、电脑一直 Connecting：检查这 5 项

手机同账号正常，只有电脑端连不上，通常不需要重新登录账号。先把范围锁定在 Desktop 的连接方式和电脑本机网络。

更新于 2026 年 9 月

1. 检查 Connection Type

Telegram Desktop 的入口在 Settings → Advanced → Connection Type。如果这里保存了旧代理，先改回正常连接方式做对照。Telegram 官方代理入口

2. 系统代理和 Telegram 代理别一起乱改

Windows / macOS 的系统代理会影响整个电脑，Telegram 内置代理只影响 Telegram。先分别单独测试，确认到底是哪一层导致 Connecting。

3. 用手机热点验证电脑网络

同一台电脑切到手机热点后马上恢复，说明 Desktop 客户端和账号大概率没坏，重点回到原来的 Wi‑Fi、公司/校园网络或路由设置。

4. 检查防火墙和安全软件

如果浏览器正常但 Telegram Desktop 完全无法建立连接，检查本机防火墙、安全软件或企业网络策略是否只影响桌面应用。不要因为手机能用就排除电脑端网络限制。

5. 最后再测试其他网络出口

只有在原网络下长期 Connecting、换热点能恢复时，再测试虎跃等其他网络出口。此时先关闭 Telegram 内置代理，避免两层代理一起参与。
