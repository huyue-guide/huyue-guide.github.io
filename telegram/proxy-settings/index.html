Telegram 代理设置：SOCKS5、MTProto 与 VPN 冲突排查

Telegram 可以单独使用应用内代理。真正容易出问题的是：Telegram 代理、系统 VPN 和其他代理软件同时存在时，连接链路叠在一起。

更新于 2026 年 9 月

各客户端的代理入口

客户端官方入口
AndroidSettings → Data and Storage → Proxy Settings
iPhone / iPadSettings → Data and Storage → Proxy
Telegram DesktopSettings → Advanced → Connection Type
Telegram for macOSSettings → Data and Storage → Use Proxy

Telegram 官方代理文档列出了这些入口，并说明常见客户端支持 SOCKS5 和 MTProto。

SOCKS5 和 MTProto 需要什么信息

SOCKS5 至少需要服务器和端口，也可能包含用户名和密码；MTProto 需要服务器、端口和 secret。缺少这些信息或代理已经失效，Telegram 就可能长时间 Connecting。

旧代理失效时，先关掉再测

暂时关闭 Telegram 的“Use Proxy / 使用代理”，保持其他设置不变。如果关闭后恢复，问题基本集中在这个代理，而不是账号或验证码。

和系统 VPN 同时开时怎么判断冲突

排查时先只保留一种方式。先关闭 Telegram 内置代理，只测试系统 VPN；再反过来，只开 Telegram 代理。哪一种单独使用稳定，就优先保留哪一种。两层同时开着时，不要靠反复切节点猜原因。

不要随便使用来源不明的代理

Telegram 官方也提醒应使用可信来源的代理。代理运营方即使看不到加密消息内容，仍可能知道你的 IP 正在连接 Telegram，且不可靠代理可能丢弃连接。查看官方安全提醒
