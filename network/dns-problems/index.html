DNS 异常怎么判断？网站打不开、App 正常时先这样排查

DNS 出问题时，常见现象不是“完全断网”，而是某些域名打不开、浏览器报找不到服务器，或者换到另一张网络后立刻恢复。先判断是不是 DNS，再决定要不要改设置。

更新于 2026 年 9 月 · 系统路径依据 Microsoft 与 Apple 当前公开帮助整理
先说结论：能访问 IP、但域名打不开，或者同一设备换网络后恢复，才比较像 DNS 问题。只有一个网站异常时，不要先把 DNS 当成唯一原因。
本页只处理 DNS：如果是开启虎跃后整台设备完全没网，先进入对应的 Windows / Mac 连接后没网页面；只有“域名解析失败、换网络恢复、浏览器报找不到服务器”这类现象才继续这里。
所有域名都报解析失败优先检查当前 DNS、路由器和网络出口。
只有一个网站打不开先查网站状态、浏览器缓存和平台限制，不一定是 DNS。
Wi‑Fi 不行，移动网络正常问题更可能集中在当前 Wi‑Fi、路由器或上游 DNS。
改过代理/VPN 后开始异常先恢复默认代理和 DNS，再做对照。

先别急着改 DNS，做两个对照

第一，换一个网络测试：例如从 Wi‑Fi 切到手机热点。第二，用另一台设备连接同一网络。如果只有当前网络下多台设备都出现同样的域名解析问题，DNS 或路由器配置就值得重点检查。

Windows 怎么检查

Windows 11 当前可以在“设置 → 网络和 Internet”里进入当前 Wi‑Fi 或以太网连接，查看 IP 与 DNS 分配。Microsoft 建议一般场景优先使用自动分配；如果需要手动 DNS，再在当前连接的 IP/DNS 设置里修改。

如果你之前手动填过 DNS、安装过网络工具，先记录原值，再切回自动获取做一次测试。不要同时改 DNS、代理、网卡参数和虎跃线路，否则很难判断是哪一步生效。

Mac 怎么检查

macOS 当前可以从“系统设置 → 网络 → 当前网络服务 → 详细信息 → DNS”查看 DNS 服务器。Apple 也支持在这里添加或删除 DNS 服务器。

如果列表里出现你不认识的手动 DNS，或者是旧软件留下的配置，可以先记录，再恢复到原本的网络设置做对照。

使用虎跃后出现 DNS 异常怎么办

先断开虎跃，再测试同一个网站。如果断开后立刻恢复，说明当前 VPN、DNS 或系统代理组合可能存在冲突；如果断开后仍然异常，就不要继续只换节点，应回到系统网络和 DNS 本身排查。

如果只有某一个平台异常，而其他域名解析都正常，更应该看对应平台页，而不是反复改 DNS。

什么时候不建议手动指定公共 DNS

公司、校园、酒店或带有门户认证的网络可能依赖自己的 DNS 或访问策略。直接改成第三方 DNS 可能让登录页、内部域名或本地服务异常。遇到这类网络，先保留自动设置通常更稳妥。
